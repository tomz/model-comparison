Scale Inversion at SF1000 (1 TB)

While DuckDB leads at small scales (SF1/SF10) due to instant zero-overhead in-process startup, Spark Rust (tuned) claims #1 in TPC-DS at SF1000 (10,074s vs DuckDB's 10,497s, a 423s / 4% lead). Native Rust multi-threading and query pipelining excel under memory pressure.

JVM vs Native Startup Penalty at SF1

Traditional Spark 4.2 and Gluten show severe bootstrap overhead at small data sizes (SF1 TPC-DS ratio 42x–45x DuckDB). In stark contrast, Spark Rust achieves instant execution, staying within ~1.17x–1.24x of DuckDB even on sub-minute queries.

Tuned vs Default Spark Rust Gains

Tuning yields measurable acceleration across all scale factors: in TPC-DS SF1000, tuned configuration cuts over 345 seconds off default runtime. In TPC-H SF1000, both Spark Rust variants run within 2.8%–4.6% of DuckDB.
