06 — Method & hardware

What was measured, on what

Hardware specifications are user-provided; benchmark figures come from the summary data file only.

Hardware

Glossary

time
Whole-suite wall-clock seconds (totals) or per-query seconds.
diff / ratio
Difference in seconds and the multiple versus the DuckDB 1.5.5 baseline (cluster rows compare Spark Rust with Gluten).
canonical / matched
Canonicalised total and matched-set ratio where the source records a validated comparison.
cpu / cpuHours
CPU-seconds consumed and the equivalent core-hours (cpu ÷ 3600).
cores
Average cores in use during the run.
memtime / memHours
Memory-time integral in GB·s and the equivalent GB-hours (memtime ÷ 3600).
p50 / p95 / max
Median, 95th-percentile and worst per-query runtime within the run.
status
Source validation label: pass, pass (Q39 ULP policy), gap, or a longer flag describing single-engine observations and rejected repeats.
P / B flags
Run annotations carried over from the source summary (their definitions live in the source report, not the data file).
