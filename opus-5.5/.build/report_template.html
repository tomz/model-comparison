Reading this report

  • Ratio (single node) is an engine's total time divided by DuckDB's total time at the same scale factor. Diff is the gap in seconds.
  • Canonical total: the source reports it separately from the raw total. It is missing ("no canonical") or different when flagged runs are involved.
  • Matched ratio: the source gives this for the all-scale-factor aggregate only. It is shown here without changes.
  • Per-query flags B and P are copied from the source data. What they mean is set out in the source report, which is not part of this dataset.
  • Cluster ratio is Spark Rust time divided by Gluten time, so values below 1 mean Spark Rust was faster. CPU is in core-seconds, per-query memory is in GB, and memory×time is in GB-seconds.
